## 💡 What is CraftIQ?
**CraftIQ** empowers rural artisans by turning any smartphone into an **AI Business Assistant**. Artisans can simply speak about their craft in their local language to generate pricing, catalog listings, and discover direct international buyers.
<br/>
## ⚡ Core Features
* 🎙️ **Voice Listing**: Speak in local languages — zero typing needed.
* 🧠 **Smart Valuation**: AI analyzes craft intricacy and recommends fair market prices.
* 🌍 **Market Matcher**: Direct connection with high-paying niche buyers.
* 📱 **Offline PWA**: Works flawlessly on low-end phones and weak networks.
<br/>
## 🛠️ Tech Stack
`React 18` • `TypeScript` • `Tailwind CSS` • `Web Speech API` • `PWA Service Workers`
<br/>
## 🚀 Quick Setup
```bash
git clone https://github.com/vidushisen/CraftIQ.git
cd CraftIQ
npm install && npm run dev
```
