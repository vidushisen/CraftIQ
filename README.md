## 💡 About The Project
> **CraftIQ** transforms any smartphone into a personal AI business manager for rural artisans. It bridges traditional craftsmanship with modern e-commerce using voice AI and instant product valuation.
<br/>
## ⚡ Key Highlights
<br/>
* 🎙️ **Voice AI Companion** — Artisans simply describe their craft in native languages; no typing required.
<br/>
* 🧠 **Smart Valuation** — AI evaluates weave, fabric, and time-investment to recommend fair market pricing.
<br/>
* 🌍 **Direct Buyer Discovery** — Matches authentic handmade crafts directly with international buyers.
<br/>
* 📱 **Zero-Friction Offline PWA** — Works smoothly in remote areas with poor internet connection.
<br/><br/>
## 🛠️ Built With
✦ React 18 ✦ TypeScript ✦ Tailwind CSS ✦ Web Speech API ✦ PWA Engine
