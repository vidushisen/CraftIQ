## 💡 About The Project
> **CraftIQ** transforms any smartphone into a personal AI business assistant for rural artisans. It bridges traditional Indian craftsmanship with modern global commerce using voice AI and automated product valuation.
<br/><br/>
## ⚡ Key Highlights
<br/>
* 🎙️ **Voice AI Companion**  
  Artisans simply describe their craft in their native regional language — no typing or technical barrier.
<br/>
* 🧠 **Smart Craft Valuation**  
  AI evaluates weave density, raw materials, and intricacy to recommend fair market prices.
<br/>
* 🌍 **Direct Buyer Discovery**  
  Auto-generates SEO-rich product catalogs and connects crafts directly to premium global buyers.
<br/>
* 📱 **Zero-Friction Offline PWA**  
  Works smoothly on budget smartphones even with weak rural internet connectivity.
<br/><br/>
## 🛠️ Built With
✦ React 18 ✦ TypeScript ✦ Tailwind CSS ✦ Web Speech API ✦ Vite PWA
