## 🌐 The Problem & The Mission
Traditional rural artisans craft world-class cultural treasures but face massive hurdles:
1. **Language & Digital Barriers**: Inability to navigate complex e-commerce portals.
2. **Unfair Middlemen**: Selling valuable authentic crafts for pennies.
3. **No Direct Market Access**: Difficulty identifying high-paying global buyers.
> **CraftIQ** transforms any smartphone into a personal AI business manager for artisans, analyzing their craft through vision & voice to provide instant valuation, automated cataloging, and direct buyer matchings.

💻 Tech Stack & Dependencies


├── Framework      : React 18 (Hooks, Suspense, Context API)
├── Language       : TypeScript (Strict Type Safety)
├── Styling        : Tailwind CSS (Modern Glassmorphism & Responsive Grids)
├── Audio Engine   : Web Speech API (SpeechRecognition & SpeechSynthesis)
└── Distribution   : Progressive Web App (PWA) + Service Workers
